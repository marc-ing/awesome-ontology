# Awesome Ontology

一个边学习、边整理的中文本体学习仓库。

目前主要关注 **Palantir 语境下的本体，以及它在中国企业 AI 项目中的应用**。从已有笔记出发，记录能理解的概念，收集相关开源项目，之后随着学习逐步补充。

## 目前对本体的理解

本体可以帮助我们描述业务中的实体、实体之间的关系，以及相关的动作和规则。

在企业场景中，可以先记成：**本体 ≈ 对象 + 关系 + 动作 + 规则**。

以订单为例：

| 要素 | 例子 |
| --- | --- |
| 对象 | 客户、订单、合同 |
| 关系 | 客户下单；订单依据合同 |
| 动作 | 催单、取消订单、修改交付时间 |
| 规则 | 已取消的订单不能发货 |

一个重要作用是帮助补齐**语义断层**：让 AI 有依据理解“订单”在这家公司中是什么意思、跟谁有关、能做什么、有哪些限制。这是对 [Palantir Ontology](https://www.palantir.com/docs/foundry/ontology/overview)的入门理解。
