## sharptoolbox 的开源项目

[sharptoolbox（人月聊 IT）的仓库列表](https://github.com/sharptoolbox?tab=repositories)是最初收集的资料来源之一，重点关注其中与本体和企业 AI 有关的项目。

| 项目 | 简单介绍 |
| --- | --- |
| [Onto-Model](https://github.com/sharptoolbox/Onto-Model) | 查看和编辑业务模型，整理对象、行为、规则及其关系 |
| [Onto-SupplyChain](https://github.com/sharptoolbox/Onto-SupplyChain) | 供应链分析演示，通过订单、库存、物料和产能分析交期；后端计算，大模型可用于解释结果 |
| [ontology-driven-dev](https://github.com/sharptoolbox/ontology-driven-dev) | 从业务需求、本体建模到应用构建，包含合同管理例子 |

这些项目采用作者自己的建模和实现方法。可以先看业务例子，再慢慢了解代码。供应链项目目前是演示，未包含真实 SAP/MES 集成。

## 微软的 Ontology Playground

[Microsoft Ontology Playground](https://github.com/microsoft/Ontology-Playground)与本体直接相关，可以通过图形界面查看、编辑对象和关系。它围绕 Microsoft Fabric IQ 提供学习内容，标为 Preview。

- [在线体验](https://microsoft.github.io/Ontology-Playground/)
- [Ontology School](https://microsoft.github.io/Ontology-Playground/#/learn)

先试着打开一个例子，看看里面有哪些对象，它们之间是怎样连接的。

## 知识问答相关项目

这一组先作为后续学习线索保留。

| 项目 | 简单介绍 |
| --- | --- |
| [OpenSPG/openspg](https://github.com/OpenSPG/openspg) | 知识图谱引擎，支持知识建模、知识构建和规则处理 |
| [OpenSPG/KAG](https://github.com/OpenSPG/KAG) · [中文介绍](https://github.com/OpenSPG/KAG/blob/master/README_cn.md) | 基于 OpenSPG 和大模型，结合领域知识、检索与推理来回答问题 |
| [Microsoft GraphRAG](https://github.com/microsoft/graphrag) | 从文本整理实体与关系，帮助检索和问答；可用于对照学习 |

这些是相关技术项目，各自关注的内容与 Palantir 本体有所不同。GraphRAG 在核对时的 README 中说明以维护为主。
